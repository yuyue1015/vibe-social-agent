# 新手指南

## 安装

将本仓库中的 `.agents/skills/vibe-social` 和 `.agents/skills/weibo-publish` 安装到目标项目的 `.agents/skills/` 下，或使用 Codex 支持的 Skill 安装方式启用它们，然后在目标项目中启动 Codex。安装后可以使用：

```text
$vibe-social
```

内容整理与外部发布由两个职责清晰的 Skill 组成：

- `vibe-social`：发现素材、生成草稿、修改和审核。
- `weibo-publish`：用户确认后的微博发布。

## 第一次运行

启动 Skill 后，你会先看到欢迎语和项目状态选择：

```text
欢迎使用 Vibe Social。

它帮助开发者从真实开发过程中发现值得分享的内容，生成内容草稿。

它不会修改源码，也不会自动发布。

请选择你的项目状态：

[1] 新项目第一次接入
[2] 已有开发中的项目
[3] 查看示例
```

### [1] 新项目第一次接入

这个项目之前没有使用过 Vibe Social。从现在开始记录开发过程。

适合：

- 新创建项目
- 第一次接入

不会创建代码项目、修改源码或初始化 Git。首次没有指定风格时，使用默认风格即可；之后可以用自然语言更换风格。

### [2] 已有开发中的项目

这个项目已经开发了一段时间。回顾 Git、文档、测试记录，寻找值得分享的开发过程。

适合：

- 已有 Git 历史
- 已有开发记录

不会上传源码，不会修改代码，只用于发现开发过程中的分享素材。明确选择要处理的项目和扫描范围。授权在这里指“允许 Skill 读取所选项目中的开发记录”，不是微博 OAuth 授权。

扫描完成后，Skill 会展示可供选择的素材。用户选择素材后，才会进入微博草稿生成。

首次扫描前会先进行轻量检查，展示项目规模、文件数量、Git 规模、文档数量、Token 范围和预计耗时。实际结果根据模型、网络速度和项目规模变化。

如果检测到项目位于父级 Git 工作区中，会先询问：

```text
[1] 只分析当前项目目录（默认）
[2] 分析整个工作区
[3] 取消
```

预计超过 50k tokens 时会提醒；预计超过 100k tokens 时，必须明确确认后才会继续分析。

### [3] 查看示例

体验一次完整流程，不使用真实项目。示例只用于理解流程和文字形态，不会自动写入真实项目的 Writing Memory，也不会发布到微博。

示例体验完成后不会停在结束提示，而是返回：

```text
示例体验完成。

请选择：

[1] 新项目第一次接入
[2] 已有开发中的项目
[3] 再看一次示例
[4] 退出
```

所有状态节点都必须同时显示当前状态、已完成动作和下一步选择，详见 [统一交互状态规范](../.agents/skills/vibe-social/references/interaction-flow.md)。

## 微博发布配置

本地内容整理不需要微博登录。风格、项目状态和发布相关选项见 [配置说明](configuration.md)。

如果要发布：

1. 先完成草稿修改和 Approve。
2. 在审核通过后的分发选择中选择：

   ```text
   [1] 发布到微博
   [2] 手动发布其他平台
   [3] 仅保存
   ```

3. 如果选择微博，安装并配置本机的 `weibo-cli`。
4. 使用 `weibo-cli` 自带的登录和状态检查流程完成账号授权。
5. 在发布入口选择微博标签、预览最终正文和图片。
6. 只有明确选择“确认发布（Publish）”后，才会执行外部写入。若能确认最终写入命令没有执行，会进入 `FAILED_RETRYABLE` 并可安全重试；`PUBLISHING` 或 `UNKNOWN_REQUIRES_RECONCILIATION` 表示结果未确认，必须先执行 reconcile，不能直接重复发布；`PUBLISHED` 禁止重复发布。

微博授权由 `weibo-cli` 管理。VibeSocial Agent 不保存微博 token，也不会因为 Approve 自动发布。

## 常见问题

### Approve 会直接发微博吗？

不会。Approve 只把当前内容保存为本地已审核草稿。发布需要单独进入 `weibo-publish` 并再次确认。

### 必须使用 Git 吗？

Skill 优先使用 Git 提交摘要和项目文档来发现开发记录。没有可用的公开安全素材时，不会为了生成内容而编造进度。

### Skill 会读取我的源码吗？

不会把源码、原始 diff、密钥或私人文件保存到社交内容状态。扫描边界和例外情况见 [隐私说明](privacy.md)。

### 数据保存在哪里？

本地状态保存在项目的 `.vibesocial/` 目录中，包括草稿、审核历史、Writing Memory、系列状态和发布记录。该目录默认被忽略，不应提交到公开仓库。

### 没有值得分享的变化怎么办？

Skill 可以返回“暂无适合公开的素材”，不会强行生成一条空泛的开发日志。

# VibeSocial Agent 产品规格

## 产品定位

VibeSocial Agent 帮助开发者从真实开发过程中发现值得分享的内容，生成微博草稿，并在确认后通过 `weibo-cli` 发布。

它是一个本地运行的开发者 Skill，不是 Web 服务、SaaS 或多用户平台。

## 用户流程

```text
安装
→ 初始化
→ 选择项目
→ 扫描开发记录
→ 选择素材
→ 生成微博草稿
→ 修改
→ 提交以上修改（Pull）
→ 审核通过并存入草稿箱（Approve）
→ 发布（Publish）
```

## 职责边界

### vibe-social

负责：

- 项目初始化和本地状态
- 选择项目后的开发记录扫描
- 隐私和知识产权筛选
- 素材选择与微博草稿生成
- 自然语言修改
- Pull 和 Approve
- Writing Memory 和系列状态的本地维护

### weibo-publish

负责：

- 消费已经 Approve 的草稿
- 发布前展示最终正文、标签和图片
- 等待用户明确确认
- 通过已配置的 `weibo-cli` 执行外部发布
- 发布后回读正文并确认发布结果

`APPROVED` 不等于 `PUBLISHED`。Approve 不会自动触发外部写入。

## 当前范围

包含：

- 本地项目状态和增量扫描
- 公共安全素材筛选
- 微博草稿生成、修改和审核
- Writing Memory 和系列状态
- 独立的、需明确确认的微博发布边界
- 发布结果的只读记录和描述性性能学习

不包含：

- Web UI
- 云端服务或远程数据库
- 多用户、团队和账号系统
- 自动审批或自动发布
- 评论处理和反馈驱动的开发自动化
- 其他社交平台

## 隐私边界

扫描和状态规则以 [隐私说明](privacy.md) 为准。`.vibesocial/` 是本地状态目录，默认被 `.gitignore` 忽略，不应提交到公开仓库。

## 成功标准

- 新项目可以通过用户引导完成初始化。
- 用户可以从真实开发记录中选择可公开素材。
- 草稿可以自然语言修改，并通过 Pull / Approve 完成审核。
- 发布必须经过独立的明确确认。
- 源码、密钥、token、私人文件和不确定内容不会进入公开内容状态。

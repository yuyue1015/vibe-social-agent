# 隐私说明

VibeSocial Agent 默认把不确定内容视为私密内容。只有经过筛选并由用户确认的素材，才会进入微博草稿和审核状态。

## 可能扫描的内容

在用户选择项目和范围后，Skill 可能参考：

- Git 提交摘要和变更范围
- 项目中的 README、CHANGELOG、报告、审计、验证和总结类文档
- 测试结果或公开安全的测试摘要
- 用户主动选择的素材和修改意见

扫描结果只用于形成面向读者的事实摘要，不保存原始 diff 或源码作为社交状态。

## 不会上传或保存到社交状态的内容

- 源码和原始 diff
- token、API key、密码、Cookie、私钥和其他密钥
- `.env` 内容和凭据文件
- 私人文件、客户数据、个人身份信息和私人消息
- 内部地址、数据库连接信息和本地绝对路径
- 未确认可以公开的路线图、商业信息或第三方材料

通过规则检查不等于内容一定适合公开。语义上的敏感性、所有权和授权仍需要人工判断。

## 本地状态目录

`.vibesocial/` 是项目本地状态目录，可能包含：

- 草稿和审核历史
- 已批准内容
- Writing Memory
- 系列计划
- 只读性能记录
- 已发布记录

该目录默认被 `.gitignore` 忽略。它不应提交到开源仓库，也不应复制给不需要这些内容的人。

## 保留策略

- 更新 Skill 时保留 `.vibesocial/`。
- 普通卸载只删除 Skill Bundle，保留 `.vibesocial/`。
- 只有用户明确选择完全移除并二次确认后，才删除 `.vibesocial/`。
- `evals/results/`、缓存、覆盖率和临时文件不属于个人状态，也不应进入 release archive。

## 发布边界

`vibe-social` 只负责内容发现、草稿、修改和审核。`weibo-publish` 负责用户明确确认后的外部发布。

Approve 不等于 Publish。发布前会再次展示最终内容，并且只有用户明确确认后才会调用 `weibo-cli`。

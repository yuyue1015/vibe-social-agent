# Anti-AI writing memory

This file is the default memory copied into `.vibesocial/anti-ai-patterns.md`. A match is a semantic warning for Draft Critic, not a blind string blacklist.

## CORE patterns to avoid by default

- “不是 A，而是 B”
- “不只是 A，更是 B”
- “这次……才发现……”
- “原来……”
- “做到这里才意识到……”
- “最有意思的是……”
- “值得一提的是……”
- “从 A 到 B，再到 C”
- “先不碰……”
- “先把这些东西理顺”
- “这个坑有点大”
- Forced questions, especially repeated “为什么……” titles or openings.
- A contrarian opening in every post, a turn in every post, or an abstract summary at every ending.
- Subjectless task-like sentences.
- Consulting/reporting vocabulary such as “推进、完善、打通、赋能、理顺、结构化表达、工程化、显性化”.
- Overly regular four-paragraph or three-paragraph summary structures.
- Invented discoveries, surprise, or “first realization” emotions added only to create a story.

## Critic behavior

Check meaning and function in context. A quoted phrase may be necessary evidence; do not delete it mechanically. Rewrite only when the phrase is acting as a generic hook, transition, or inflated summary.

# Performance Learning

Performance Learning is read-only and descriptive. It may use only fields actually returned by the installed CLI after the live schema and login checks pass.

- `performance.py snapshot` records one local record per published Social Commit.
- `performance.py analyze` produces observations only after at least five distinct published posts have usable snapshots.
- Missing metrics remain missing; never fabricate views, likes, comments, reposts, exposure, image counts, or timing fields.
- Performance Insights cannot automatically rewrite content or Writing Memory. Precedence remains factuality → Writing CORE → series plan → approved-content de-duplication → Performance Insights → generic social advice.

If the CLI schema, login state, or metric fields are unavailable, record no fabricated result and continue the editorial workflow.
